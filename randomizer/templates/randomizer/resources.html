SMRPG Remake Randomizer

How to Play

The 2023 Switch remake of SMRPG also has a randomizer! You can find info about how to play it on GitHub.

The remake randomizer project is NOT officially affiliated with the SMRPG Randomizer project and our developers do not work on it. The remake randomizer developers are also not in any of the SMRPG discords, so you will have to get in touch with them elsewhere if you want to contribute to developing it.

SMRPG Remake Modding Discord Server

Though not as active as the SNES modding discord, this server is full of great resources if you're interested in contributing to the randomizer project for the Switch release of SMRPG!
